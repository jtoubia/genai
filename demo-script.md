# CuisineIQ — Optional 2–3 Minute Demo Script

**This script is a recording aid, not an assignment submission requirement.** Submit the narrated video file (and repository link), not this document. Adjust the narration to match the website as it actually behaves on recording day.

## 0:00–0:25 — Problem and user

“CuisineIQ is an international cooking assistant for people who want to try dishes from different cuisines but may not know the ingredients, substitutes, or cooking techniques. The goal is to make the process manageable from selecting a dish all the way through shopping and cooking.”

**On screen:** Show the home page, dish search, and suggested recipes.

## 0:25–1:05 — Main workflow and AI value

“I can type a dish rather than being restricted to a small dropdown. For example, I'll use Ethiopian Doro Wat, set three servings, choose dairy-free, and make it mild. The intended AI capability is to generate a recipe for a dish request and adapt its ingredients and instructions to the user's preferences. It is not just a calculator for ingredient quantities.”

**On screen:** Enter the dish/settings and generate. Point out the result and any provenance label. If a live model is confirmed, call it live AI; otherwise describe the output as a prototype demonstration.

## 1:05–1:40 — Meaningful revision from feedback

“One of the biggest improvements came from peer feedback and my own testing. Previously, users had to type ingredients they already had before seeing the recipe. That was confusing for unfamiliar dishes, and wording differences such as ‘potato’ and ‘potatoes’ could cause problems. Now, CuisineIQ shows the full ingredient list first. I check off what I already have, and the shopping list updates automatically. The cooking instructions still include those ingredients, because I still need them to make the dish.”

**On screen:** Check one or two ingredient boxes; show their removal from the shopping list.

## 1:40–2:05 — User control and shopping location

“The site also explains substitutions and lets users review important choices. For this dairy-free dish, it does not silently choose an uncertain replacement for niter kibbeh; it asks the user to choose an alternative or leave it out. I can also enter a ZIP code for shopping context, but the prototype does not yet claim live store inventory.”

**On screen:** Highlight the substitution choice and ZIP code section.

## 2:05–2:35 — Evaluation, limitation, and next priority

“I ran seven distinct tests, with six reported passes and one partial result, plus three repeated runs of the same AI request. Those repeated results were identical. One issue remains: an empty dish search correctly shows an error, but the previous plan can still remain visible through Update My Plan. My next priority is fixing that stale-plan behavior and more thoroughly testing restrictions against incompatible substitutions. This is a prototype, so users still need to verify recipe details and ingredient labels.”

**On screen:** Briefly show the empty-input validation only if it won't derail the walkthrough, then end on the useful recipe/shopping output.

- Save as MP4 or MOV; upload to Google Drive and share with both named instructors.

- Do **not** claim the live model, store inventory, or specific safeguards work unless you have confirmed them.
